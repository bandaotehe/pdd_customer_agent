# Customer-Agent 使用文档

## 一、启动与配置

### 1. 启动程序

解压 `AgentCustomer.zip`，双击 `AgentCustomer.exe` 启动。

### 2. 配置模型

点击左下角 **「设置」**，依次填写以下三个模型配置：

**LLM 模型配置：**

| 配置项 | 说明 | 示例 |
|--------|------|------|
| API Base URL | LLM 接口地址（OpenAI 兼容） | `https://api.example.com/v1` |
| API Key | 接口密钥 | `sk-xxxxxxxxxxxxxxxxxxxxxxxx` |
| 模型名称 | 大语言模型名称 | `qwen3.6-plus` |
| 视觉能力 | 勾选后支持理解图片/视频 | 推荐勾选 |

**嵌入模型（知识库配置 → 嵌入模型）：**

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 提供方 | `openai` 或 `local` | `openai` |
| 模型名称 | 嵌入模型名称 | `text-embedding-3-small` |
| API Key | 为空则复用 LLM 的 Key | 留空即可 |
| API Base | 为空则复用 LLM 的 Base | 留空即可 |
| 向量维度 | 模型输出向量维度 | `1536` |

**重排序模型（知识库配置 → 重排序）：**

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 提供方 | `api` 或 `local` | `api` |
| 模型名称 | 重排序模型名称 | `qwen3-reranker-8b` |
| API Key | 为空则复用 LLM 的 Key | 留空即可 |
| API Base | 为空则复用 LLM 的 Base | 留空即可 |

其余设置项（Prompt 指令、营业时间、OSS、分块参数、数据库路径）保持默认即可，点击顶部「保存设置」。

## 二、账号管理

### 1. 添加账号

点击左侧 **「账号与客服」** → **「账号管理」** 标签页 → 点击 **「添加账号」**：

- 输入拼多多客服的 **用户名** 和 **密码**
- 点击 **「验证」**，等待 Playwright 自动登录，验证成功后会显示绿色「在线」标识

### 2. 启动自动回复

切换到 **「自动回复」** 标签页：

1. 点击 **「上线」** — 向拼多多平台设置在线状态
2. 点击 **「开始回复」** — 启动 WebSocket 连接 + AI 自动回复

两个按钮依次点击后，拼多多后台将显示在线，客户的咨询消息会自动由 AI 处理回复。

## 三、同步产品知识库

点击左侧 **「知识管理」** → 顶部选择店铺 → 点击 **「同步产品知识」**：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **增量同步**（推荐） | 仅同步本地尚不存在的商品，已有商品跳过 | 日常同步、新商品上架 |
| **全量同步** | 重新拉取拼多多所有商品，覆盖已提取的知识 | 首次使用、知识提取效果不佳需重建 |

同步过程分两阶段：
1. **抓取商品列表** — 分页拉取拼多多全部商品基本信息
2. **LLM 提取知识** — 调用大模型分析每个商品详情，提取成分、规格、功效等结构化知识

完成后可在「产品知识」表格中查看所有同步结果。

## 四、应用场景示例

### 场景一：补水上架了新款保湿面膜

1. 广告上线后，客户点进商品页咨询「这个面膜什么成分？」「敏感肌能用吗？」
2. 拼接一键 **增量同步**，系统自动拉取新商品并调用 LLM 提取成分、适用人群、使用方法等知识
3. AI 客服回答时自动调用 `get_product_knowledge` 查知识库，给出准确回复

### 场景二：客服手册新增了退换货政策

1. 运营在 **「知识管理」→「客服知识」** 中手工录入「退换货政策」FAQ
2. 客户咨询「怎么退货？」时，AI 不会触发转接（退换货政策属于售前咨询），而是搜索知识库给出政策说明
3. 客户进一步说「我要退款」→ 关键词触发，直接转接人工售后

### 场景三：每天上班启动客服系统

1. 双击 `AgentCustomer.exe` 启动
2. 打开 **「账号与客服」→「自动回复」**，依次点「上线」→「开始回复」
3. 系统自动接收 WebSocket 消息，AI 处理售前咨询，售后关键词自动转人工
4. 下班时点「停止回复」关闭 WebSocket

### 场景四：月末批量上架 50 个新品

1. 拼多多商家后台批量上架商品
2. 打开本系统，进入「知识管理」，选择店铺后点 **「增量同步」**
3. 系统自动抓取 50 个新商品，LLM 逐个提取知识，几分钟后全部入库
4. AI 客服立即拥有这 50 个新品的产品知识，客户咨询时自动查取

### 场景五：知识库内容过时需要重建

1. 商品配方更新、规格变更，之前同步的知识已不准确
2. 打开「知识管理」，选择店铺后点 **「全量同步」**
3. 系统重新拉取所有商品，调用 LLM 重新提取知识，覆盖旧数据
4. 同步完成后 AI 客服使用最新产品知识回复客户

## 五、常见问题

### 拼多多后台在线状态掉了

关闭 `AgentCustomer.exe`，重新启动，按照「二、账号管理」的步骤重新「上线」→「开始回复」即可。

### 其他异常

遇到任何异常情况（AI 回复异常、消息不回复、界面卡顿等），直接关闭程序重新启动。大部分问题重启后自动恢复。
